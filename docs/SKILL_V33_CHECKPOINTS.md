# Skill V3.3 — locked causal checkpoints

V3.3 is a forward-only process upgrade created after the consumed 2025-09 refrigerant window.

## Problem

V3.2 correctly distinguished short event-repricing from structural multi-year theses, but a remaining ambiguity appeared:

- the physical/policy regime can remain intact;
- company profit can remain high;
- yet incremental earnings growth and the expectation gap can close.

A structural thesis therefore needs more than an entry-time horizon classification.

## V3.3 change

Every Candidate must predeclare a checkpoint plan before outcome data is opened.

At each checkpoint the researcher must refresh only point-in-time evidence and separately classify:

1. **causal regime** — intact / weakening / broken;
2. **earnings surprise** — accelerating / stable / decelerating / closed / broken;
3. **expectation gap** — widened / open / closing / closed / unknown.

Then freeze one decision:
- Continue;
- Downgrade;
- Exit.

Only after that checkpoint lock may the next outcome segment be opened.

## Why this is not overfit

V3.3 does not introduce a return threshold, stop-loss percentage, valuation cutoff or mandatory 120-day exit.

The new rule is epistemic: it forces a second point-in-time underwriting decision before a long-duration thesis is allowed to coast on its original story.

## Historical integrity

Consumed windows remain consumed and are never rescored as fresh evidence.

The first untouched window eligible to use V3.3 is 2025-12.
