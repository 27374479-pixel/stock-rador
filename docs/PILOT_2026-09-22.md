# Forum-lead point-in-time pilot — 2026-09-22

This pilot is a development-set sanity check, not statistical alpha proof. The selection rule and threshold were frozen in `config/pilot_cases.json` before post-signal returns were retrieved. Signal-day selection used only forum metadata, company evidence published no later than the signal date, and pre-signal price history. Future returns were used only for evaluation.

Trading assumptions: T+1 open, 0.10% cost on each side, adjusted prices for returns, unadjusted daily bars for suspension/one-price limit execution blockers, and CSI 300 as benchmark.

## Development-set lessons

1. The early 2023 transformer practitioner signal plus direct A-share exposure mapping did select 金盘科技 before outcome retrieval, and that candidate later produced large long-horizon excess return. This is encouraging but is only one selected trade.
2. A repeated late transformer signal in 2024 did not produce durable excess returns for the mapped basket. A theme can remain physically true while no longer being an attractive stock signal.
3. The current novelty penalty is too blunt. The 2023-11 800G case was already discussed in company disclosures, so the frozen rule abstained, yet 中际旭创 and 新易盛 subsequently produced very large excess returns. "Already public" is not equivalent to "fully priced."
4. V2 must separate factual novelty from magnitude/earnings surprise and price digestion. These four cases are now development data and must not be reused as an unbiased validation set after changing the rule.

The next validation must freeze V2 first and then evaluate a fresh, untouched set of dates/cases.
